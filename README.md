An interactive web-based learning and experimentation platform for **Digital Image Processing (DIP)** and **Medical Imaging Physics**, enabling learners to study mathematical foundations, compare **Python (OpenCV / NumPy / Scikit-Image)** and **MATLAB** implementations, and process real images in real time.

---

## 🎯 Objectives & Purpose (วัตถุประสงค์ในการพัฒนา)

1. **Interactive Education (การเรียนรู้เชิงโต้ตอบ):** Bridge the gap between mathematical theory and practical implementation by allowing students to adjust parameters (e.g., Window/Level, FFT cutoff radius, CLAHE clip limit, Radon angle step) and observe results immediately.
2. **Bilingual Code Reference (คลังโค้ดอ้างอิง 2 ภาษา):** Provide structured Python and MATLAB code lessons ([`diplab.org/lessons`](https://www.diplab.org/lessons)) in both English and Thai for all 12 core DIP modules.
3. **Medical & Scientific Imaging Focus (เน้นประยุกต์ใช้ทางการแพทย์และวิทยาศาสตร์):** Support clinical & research workflows such as 8-bit Medical Window/Level LUTs, Multi-modal Alignment & Fusion (CT + PET/MRI), and Computed Tomography (CT) Reconstruction (Sinogram, BP, FBP, MLEM, OSEM).

## 💻 12 Interactive Modules

| # | Module | Key Capabilities |
| :-: | :--- | :--- |
| 01 | **Histogram Equalization** | GHE, CLAHE, BBHE, DSIHE, Histogram Specification (Gaussian/Rayleigh/Uniform), Entropy |
| 02 | **Color Space Conversion** | RGB ↔ Grayscale, Pseudocolor (JET/Viridis), RGB ↔ HSI Split, `[0, 1]` Normalization |
| 03 | **Frequency Domain** | 5-Stage Interactive 2D FFT, Filter Masks $H(u,v)$ (LPF/HPF/BPF/BSF), Inverse FFT |
| 04 | **Gray Transformations** | Negative, Log, Inverse Log, Power-Law (Gamma), Threshold & Contrast Stretch, Bit-plane |
| 05 | **Look-Up Table (LUT)** | Mode 1: 1D Tone Curves, Mode 2: Medical Window/Level `[0-255]`, Mode 3: Pseudocolor 3D LUT |
| 06 | **Image Filter** | Noise Injection (Gaussian / Salt & Pepper), Spatial & Frequency Filters, MSE/PSNR/SNR |
| 07 | **Restoration & Denoise** | Non-Local Means Denoising (NLM), Interactive Brush Mask Inpainting (Navier-Stokes) |
| 08 | **Image Segmentation** | Global Binary Threshold, Otsu's Automatic Method, Adaptive Gaussian Threshold |
| 09 | **Image Compression** | Multi-Format (`.jpg`, `.png`, `.webp`, `.tiff`, `.bmp`), Savings %, PSNR & File Download |
| 10 | **Image Morphology** | Erosion, Dilation, Opening, Closing, Top-Hat, Black-Hat, Skeleton, Hit-or-Miss, Convex Hull |
| 11 | **Alignment & Fusion** | Auto SIFT/ORB (Projective/Affine/TPS) & Manual D-Pad (Pan/Rotate/Zoom/Shear) + 5 Fusion Modes |
| 12 | **Image Reconstruction** | Radon Transform (Sinogram), Backprojection (BP), Filtered BP (FBP), MLEM, OSEM |

## 🔒 Privacy & Data Handling Policy

- **Privacy Policy:** Full details on account security, transient image processing, cookies, and third-party advertising disclosures are available at [https://www.diplab.org/privacy](https://www.diplab.org/privacy).
- **Transient Image Processing:** Images uploaded to the Processing Lab are processed in memory via HTTPS solely to execute the requested DIP operation and are not permanently stored, sold, or shared.
